Steps to Utilize:

1- You input in the paths to the Group Data Table, Subject Data Table, and the Group Statistical Results. The data then loads into the system. There is a loading icon that runs until the system has loaded the data.

2- Right now, you can only select the “Manual” Mode. That means you will need to select some parts of the configuration to plot what you want.

3- A dropdown will show up that has the names of the 3 main data sheet we utilized (Group Statistical Results, Group Data Table, and Subject Data Table). Select the one you want to use for the main plotting data.
In this first example I’m using the Subject Data Table, which has the rawest form of the scalar data. A set of configuration options appears based on the main data table type.

4-For the plotting to work you need to select what from the data table you want for the x axis, the y axis, if filtering based on the Group Statistical Result is desired. All radial buttons require input to plot (even if you have selected NONE for the filter). You then select what groups you want to include into the plot. The plot will generate each individual as a point and will indicate the separate groupings as individual colors. In this first example plot I’m showing the top 10 regions in FA mean comparing Old and Young. Using the Group and Subject Data Tables, the top number is determined by the maximal difference between the groupings indicated, while top number for the stat results is determined by ranking the values plotted on the y axis. 
There is a download CSV button. You can save generated figures as editable svgs by hovering over the right corner of the graphing area.
NOTE: for the subject data table we have ALL the data in the table because it is the RAWEST form of the data. If you are using the bilateral data for the Group Statistical Results and Group Data Table but indicate Left, you will get nothing in the plot if you try to filter! This is by design.

YOU can also work with the Group Data Table in a similar way but showing only the "Group means" for the scalar contrast or the Group Statistical Result showing one statistical results per ROI.
